Current prototype behavior
    

  • Chosen structure: one window per leaf; exactly two children per split. The first window fills an empty screen. Directions alternate from the screen root and always follow current depth.
    • 

  • Create: split the focused tiled window 50/50. Outer (default) puts the new window toward the nearer screen edge along the split axis; Inner puts it on the opposite side, toward the screen center. A centered tile uses right / bottom for Outer and left / top for Inner. Changing the setting affects future creation only. When focus is floating, split the remembered tiled window, or the last tile in tree order if it is gone.
    • 

  • Delete / float: remove the tile and promote its sibling. Directions follow depth, so promotion can rotate an existing subtree.
    • 

  • Drag: inside the immediate parent, swap with the whole sibling section. Outside that parent, swap individual windows without changing the split structure. After crossing the boundary, that drag stays in window-swap mode until release; dragging back reverses the swap.
    • 

  • Move buttons: swap the whole sibling section when moving toward it; otherwise swap with the nearest window outside the parent in that direction. Unavailable directions are disabled.
    • 

  • Floating: excluded from the tree. Drag freely or nudge with the move buttons. Tiling again splits the remembered tiled window and places the returning window second (right / bottom).
    • 

  • Screens: independent trees and root directions. “Other screen” transfers the focused window and follows it. No minimum tile size or automatic rebalancing yet.
