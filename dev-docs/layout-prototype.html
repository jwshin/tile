Chosen model & working rules
    

  • Chosen structure: one window per leaf; exactly two children per split. The first window fills an empty screen. Directions alternate from the screen root and always follow current depth.
    • 

  • Create: split the focused tiled window 50/50. New windows default to the left for horizontal splits or top for vertical splits. “New window placement” can reverse this to right / bottom; it affects future creation only. When focus is floating, split the most recently focused remaining tile.
    • 

  • Delete / float: remove the tile and promote its sibling. Directions follow depth, so promotion can rotate an existing subtree.
    • 

  • Move: buttons swap with the nearest tiled window in that direction. At an edge, nothing happens. Dragging swaps when entering another tile.
    • 

  • Floating: excluded from the tree. Drag freely or nudge with the move buttons. Tiling again splits the most recently focused tile.
    • 

  • Screens: independent trees and root directions. “Other screen” transfers the focused window and follows it. No minimum tile size or automatic rebalancing yet.
