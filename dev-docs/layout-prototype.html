Current rules
    

  • One window per leaf; exactly two children per split. Directions follow depth. New splits start 50/50; resizing retains their ratios.
    • 

  • Every tiled insertion uses Outer / Inner. Windows that cannot fit float. The baseline minimum is 320 × 200, with larger known limits taking precedence.
    • 

  • Within the parent, swap whole sibling sections. Beyond it, swap individual windows. Dividers stay put; swaps violating minimums are rejected.
    • 

  • Cross-screen transfers preview while hovering and commit on release. Source-screen swaps made during that gesture are discarded.
    • 

  • Closing uses recent focus, including floats. Directional focus skips floats, crosses screens, and never wraps.
    • 

  • Removal promotes the sibling. If a changed screen or rotation cannot fit, clamp ratios, then float the least recently focused tiles.
    • 

  • Minimized, hidden, and fullscreen windows leave the tree. Disconnection migrates windows individually; reconnecting does not move them back.
